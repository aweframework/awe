Rules captured

Contrast ≥ 4.5:1 in light and dark with any primary; visible :focus-visible ring everywhere; motion off with prefers-reduced-motion; tokens only, never a colour literal or a palette primitive in a component; a new token goes in the token file and ships in both engines. Full rules per component: website/docs/design-system/components.md, shell: layout-and-shell.md.
