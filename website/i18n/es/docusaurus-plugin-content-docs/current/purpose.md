## Introducción {#introduction}

Queremos crear un producto que ayude a las empresas de software a superar los problemas a los que pueden enfrentarse:

* Los equipos de desarrollo grandes implican **enormes costes de formación** en nuevas tecnologías y la pérdida de foco en la lógica de negocio.
* **Necesidad de migrar** las aplicaciones antiguas en lugar de reconstruirlas desde cero.
* La evolución tecnológica se acelera y necesitamos un **proceso de desarrollo estable**.

## ¿Qué es AWE? {#what-is-awe}

AWE es un motor que permite a los desarrolladores definir estructuras que se traducen
en pantallas web, **sin necesidad de saber nada sobre desarrollo web** y quedando aislados
de la evolución de la tecnología web, pero beneficiándose de ella.

AWE también proporciona algunas herramientas para facilitar el desarrollo web, como:

* Capacidad de utilizar diversos métodos de **autenticación**.
* Realizar **consultas** a bases de datos SQL y NO-SQL.
* Enviar/recibir mensajes a través de **colas JMS**.
* Lanzar **servicios** para interactuar con su lógica de negocio:
  * Llamadas directas a métodos **Java**.
  * Conexión con arquitecturas de **microservicios**.
  * Llamadas simplificadas a API **REST**.
* Composición automática de **correos electrónicos** de forma sencilla.
* Obtener los datos de una pantalla como **informe**.
* Soporte **multiidioma**.
* Personalizar su aplicación con nuestros **temas** de color.
* Añadir nuestras **pantallas pregeneradas** listas para usar.

## Módulos {#modules}

Existen varios módulos desarrollados alrededor de AWE que ofrecen funciones útiles para el desarrollo y la gestión de aplicaciones:
* **Developer**: Herramientas de desarrollo para facilitar la creación de aplicaciones AWE. Este módulo proporciona varias funciones, como la generación dinámica de locales o la generación de pantallas CRUD. 
* **Scheduler**: Planificador de procesos. Permite ejecutar tareas programadas cuando se cumple una condición: lanzamiento en una fecha concreta, cuando cambia un archivo o de forma manual.
* **Tools**: Conjunto de herramientas DevOps que pueden integrarse como opciones de la aplicación. Proporciona un lanzador de consultas SQL y un gestor de archivos.
* **Rest**: Módulo que genera automáticamente una API REST para la aplicación generada con AWE. Documentación automática proporcionada por Swagger.
