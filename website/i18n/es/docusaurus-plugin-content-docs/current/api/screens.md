En AWE, las pantallas se generan a partir de un *descriptor XML* y una *plantilla JSP*. Las páginas HTML finales se generan automáticamente a partir de esos 2 archivos.
Para cambiar una pantalla solo es necesario actualizar el *descriptor XML* de la pantalla; la *plantilla JSP* no necesita modificarse.

:::tip
Todos los elementos y atributos de las pantallas están listados en la [referencia XSD](/reference/screen) generada.
:::

:::info
**Nota:** Todos los descriptores XML de pantalla se definen en la **carpeta de pantallas**. Consulta la [estructura del proyecto](../guides/project-structure.md) para más información.
:::
