Las opciones de aplicación son una forma de añadir valores de propiedades mediante la base de datos. Las opciones de aplicación
se tratan como propiedades y sobrescribirán las propiedades ya definidas con la misma clave.

## Pantalla de parámetros de aplicación {#application-parameters-screen}

Para gestionar las opciones de aplicación, debe navegar a `Tools -> Application parameters`.

<img alt="Pantalla de parámetros de aplicación" src={require('@docusaurus/useBaseUrl').default('img/ApplicationOptions.png')} />

Allí dispondrá de una pantalla donde podrá añadir, actualizar o eliminar las opciones de aplicación en tres
categorías:

* **Security**: Propiedades relacionadas con la seguridad 
* **Reports**: Propiedades de generación de informes
* **General**: Otras propiedades
