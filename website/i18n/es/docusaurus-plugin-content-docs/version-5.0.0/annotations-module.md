El módulo `annotations` incluye un conjunto de anotaciones orientadas a Spring para facilitar la gestión de algunas funcionalidades de AWE.

Para incluir este módulo, basta con añadir la dependencia al descriptor pom:

```xml
<dependencies>
...
  <dependency>
    <groupId>com.almis.awe</groupId>
    <artifactId>awe-annotations-spring-boot-starter</artifactId>
  </dependency>
...
</dependencies>
```
