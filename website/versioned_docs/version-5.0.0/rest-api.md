# AWE Rest API

## Authentication

- `bearerAuth`: HTTP bearer, JWT. AWE local JWT token obtained from /api/authenticate.

## Authentication API

Authentication service

### `POST /api/authenticate`

**Authentication service.**

Provides a JWT token to be sent as http header in services that require authentication.

**Security:** none (public)

**Request body**

- `application/json`: [`LoginRequest`](#loginrequest)

**Responses**

| Status | Description | Body |
|---|---|---|
| `200` | Success. Authorized OK | [`LoginResponse`](#loginresponse) |
| `400` | Bad request | [`AweRestResponse`](#awerestresponse) |
| `401` | Unauthorized. User not found, invalid credentials or expired password (code PASSWORD_EXPIRED: the password has to be changed in the web application) | [`AweRestResponse`](#awerestresponse) |
| `403` | Forbidden | [`AweRestResponse`](#awerestresponse) |
| `500` | Internal error | [`AweRestResponse`](#awerestresponse) |
